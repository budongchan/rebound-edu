# 리바운드에듀 역할별 기능 명세

## 학생 (student)
- 회원가입/로그인 (이메일, 카카오, Google)
- 강의 카탈로그 탐색 (카테고리 필터: 중개업/숙박업/사업장/AI자동화/투자개발)
- 강의 상세페이지 (커리큘럼, 강사소개, 후기, 미리보기)
- 강의 결제 (토스페이먼츠 - 카드/계좌/간편결제)
- VOD 시청 (HLS 스트리밍, 배속, 구간반복, 진도율 자동저장)
- Q&A 질문 작성 (강의별 게시판)
- 수료증 발급 (PDF, 고유번호)
- 수강 이력/결제 내역 조회

## 교사 (teacher)
- 강의 기획서 작성 및 등록
- 영상 업로드 (자동 인코딩/CDN)
- 스케줄 관리 (촬영/리허설/무료특강/본강의 - 캘린더)
- 수강생 현황 대시보드 (수강률/완강률/이탈구간)
- Q&A 답변
- 정산 대시보드 (월별 매출/수익 배분/정산 이력)

## 직원 (staff)
- 학생 DB 관리 (검색/필터/엑셀 다운로드)
- 교사 DB 관리 (프로필/강의현황/계약상태)
- CS 1:1 상담 (접수/배정/처리/완료)
- 환불 처리 (PG사 자동 환불 연동)
- 콘텐츠 검수 (화질/음질/메타데이터)
- 프로모션/쿠폰 관리

## 관리자 (admin)
- 사용자 역할 부여/변경
- 가입 승인 (교사/직원/관리자 신청 승인/거절)
- 강의 최종 승인
- 매출/KPI 대시보드
- 시스템 설정 (약관, 수수료율, 정산주기)
- 공지/배너 관리

## 공통
- 채널톡 상담 버튼 (모든 페이지 플로팅)
- 카카오 알림톡 (결제확인/강의오픈/스케줄 리마인더)
- Supabase RLS 기반 역할별 접근 제어
